# Project Instructions

## Coding rules

The coding rules, gated by `src/devkit_tests/conventions/`, live in [coding.md](./coding.md).

## ASCII-only text

Use only ASCII characters for punctuation and dashes in prompts, comments, docs and skills. Do not use Unicode
lookalikes such as em dashes (`--` instead), en dashes (`-` instead), non-breaking hyphens or arrows (`->` instead).
